# Dance Studio

A basic Dance Studio web application built using Angular and TypeScript.

## About

This project is a simple Angular application created to demonstrate the fundamentals of building a web application for a dance studio.

The application includes basic pages for users to explore the studio, instructors, courses and contact information.

## Features

- User login
- Dashboard
- Dance courses
- Instructor information
- Contact page
- Basic navigation
- Image slideshow
- Responsive user interface

## Technologies Used

- Angular
- TypeScript
- HTML5
- CSS3
- JavaScript
- Angular Router
